Gates widened: the helpers and evidence entry points are executed under Bun and Deno in CI (not only the runtime); the TypeScript compat job parses all 23 committed schema fixtures under TypeScript 5, 6 and 7 roots and requires byte-identical results; the ambient-capability tarball scan also rejects `process.env` outside the CLI and the ESLint plugin; the `node:fs` import ban in `src/` is live again (two flat-config blocks had let the later one replace it); a `required` CI check stands for every job the ruleset could not name, and `contract` fails instead of skipping when `verify` or `lint` fails; `npm run setup` installs the shared git hooks.

Documentation now matches the gates behind it: coverage is described as fixed floors raised in review (not a self-moving ratchet); the compiler is described as bundled, about 24 MB; SECURITY names all six entry points in its no-network statement; VERSIONING's Private tier covers every entry point; the Action's `version` input is documented as required when env-cap is not installed, and the workflow examples install the package first; ADRs 0014 and 0023 carry their real status; `rotationStatus` is documented as a policy-window judgement, never a compliance statement, with the 1.0 rename announced. The Action's step summary is capped below GitHub's size limit.

TypeScript 7 consumers no longer need `skipLibCheck`: the build emits a second declaration tree (`dist/.dts7`) whose compiler-API types come from the bundled TypeScript 6, served only to TypeScript 7 through `types@>=7` export conditions; TypeScript 5 and 6 keep the declarations typed from their own `typescript`. The compat job type-checks every entry point but `./eslint-plugin` (typed through its `@typescript-eslint/utils` peer) with full library checking under all three and asserts which declaration set answered.
